fEco_dly (Echo Delay Flag)
에코가 사라지면 30초 쉬었다가 다시 시도하는 안전장치

한마디로

에코가 연속으로 감지되지 않으면, 무의미한 분석을 반복하지 않고 30초간 대기한 뒤 다시 시도합니다.

비유 안개가 짙어서 앞이 안 보일 때, 무리하게 운전하지 않고 잠시 멈춰서 안개가 걷히길 기다리는 것과 같습니다.

왜 필요한가?

탱크 내 거품, 교반, 파도 등으로 에코가 일시적으로 사라질 수 있습니다.

  • 계속 분석하면 노이즈를 에코로 오인 → 엉뚱한 값 출력 위험
  • 30초 쉬면서 상태가 안정될 시간을 확보

TRUE 발동 조건 (2가지)

조건기준결과
Echo Delay 초과미검출 > EchoDly 설정에러 + TRUE
측정간격+3 초과미검출 > Intv + 3사전보호 TRUE

30초 후 복귀

MsANL_Proc1Sec() 함수가 1초마다 대기 카운터를 +1 하고, 30에 도달하면:

  • fEco_dly → FALSE (지연 해제)
  • cErr_eco0 → 0 (에러 카운터 리셋)
  • 다음 측정부터 정상 분석 재개
반복 가능 30초 후 재개했는데 또 에코가 없으면 → 다시 TRUE → 다시 30초 대기. 에코가 돌아올 때까지 반복됩니다.

관련 변수

변수역할
fEco_dly에코 지연 플래그 (TRUE / FALSE)
cErr_eco0에코 미검출 연속 횟수
cEco_wt30초 대기 카운터 (0 → 30)
fEco_chk현재 에코 존재 여부
